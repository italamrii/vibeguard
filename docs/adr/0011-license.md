# ADR-0011: License under Apache-2.0

- Status: Accepted
- Date: 2026-11-03

## Decision

VibeGuard is licensed under the Apache License 2.0. Compared with MIT, it adds an
explicit patent grant and patent-retaliation clause. That is common for security tooling
that companies embed (for example OSV-Scanner and Trivy), and it keeps
contributions under the same terms (section 5) without a separate CLA.
